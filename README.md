# oop_cpp
Orientação a Objeto com C++

# Pré-Requisitos:

Ter no mínimo a versão C++ 17 instalada

# Compilação

Executar o seguinte código no terminal do seu computador:

    g++ *.cpp -o main.out -std=c++17

# Execução

Executar o seguinte código no terminal do seu computador:

    ./main.out
